04 / Supported VR deployment model

Meta Quest standalone: Use Meta Horizon Platform SDK Device & Application Integrity. Meta currently documents Quest 2, Quest Pro, Quest 3 and Quest 3S support for this Android-platform API.
Android VR distributed through Google Play: Use Google Play Integrity Standard API. The client supplies the request hash and sends the returned token to this backend.
PCVR / SteamVR / other OpenXR runtimes: Use the platform's own authentication or anti-cheat solution. OpenXR itself does not issue a universal hardware-attestation token. Do not label these sessions Meta- or Google-verified.
