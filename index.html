02 / COMMAND DIRECTORY

Find your next command.

BROWSE THE TOOLKIT

Prefix shown as !. Replace bracketed arguments with the relevant user, text or number. Moderation commands require the matching Discord permissions. Some counters and poll records are held in memory and reset when the bot restarts.
03 / GETTING STARTED

Bring the laughs to your server.

QUICK SETUP

Invite & configure

01Invite the botUse your bot's Discord OAuth2 invite link from the Developer Portal. Choose only the permissions it needs.
02Enable required intentsIn Developer Portal → Bot, enable Message Content Intent and Server Members Intent.
03Set the prefixDefault prefix is !. The bot also responds when mentioned.
04Try a commandRun !help in a server channel where the bot can read and send messages.

Example terminal

# Try these in your Discord server
!help
!ping
!joke
!rps rock
!daily
!poll Movie night? | Comedy | Action
