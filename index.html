How genuine attestation works

  1. Backend generates a unique Base64URL nonce (22–172 chars).
  2. Your native Quest app calls getIntegrityToken(challengeNonce).
  3. Meta signs the token; your app sends it to your backend.
  4. Backend calls Meta's /platform_integrity/verify endpoint.
  5. Backend validates nonce, timestamps, package, signing digest and device state.

ADB NETWORK MODEL

Why a local companion?

Render is a cloud server and cannot discover devices on your home Wi-Fi. Android Debug Bridge must execute on a computer with Android Platform Tools installed and network access to the Quest.

Run python adb_agent.py on that computer. Protect it with a strong ADB_AGENT_TOKEN; do not expose the companion publicly without a secure tunnel and origin restrictions.

The companion exposes only device listing, wireless pair/connect/disconnect and basic read-only device information. It does not root the headset or access another app's private data.
